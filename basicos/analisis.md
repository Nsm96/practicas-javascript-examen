# Análisis — Ejercicios básicos

Antes de mirar una solución, intenta responder a las preguntas de cada  
ejercicio. Después, si lo necesitas, lee las pistas.

## Ejercicio 1: Clasificar un número

### Para pensar

- ¿Qué número tienes que comprobar?
- ¿Cuántas posibilidades hay?
- ¿Qué estructura te permite elegir entre varias opciones?
- ¿Qué mensaje debe mostrarse en cada caso?

### Pistas

- Necesitarás una variable para guardar el número.
- Necesitarás comparar el número con 0.
- Puedes usar `if`, `else if` y `else`.
- Al final tendrás que mostrar el mensaje correspondiente.

## Ejercicio 2: Calcular un descuento

### Para pensar

- ¿Qué dato es el importe inicial?
- ¿A partir de qué cantidad se aplica el descuento?
- ¿Qué porcentaje se aplica?
- ¿Cómo se calcula el descuento?
- ¿Cómo se obtiene el precio final?

### Pistas

- Necesitarás una variable para el importe.
- Necesitarás comprobar si el importe llega a 100.
- El descuento se calcula multiplicando el importe por el porcentaje  
  y dividiendo entre 100.
- El precio final es el importe menos el descuento.
- Tendrás que mostrar tanto el descuento como el precio final.

## Ejercicio 3: Tabla de multiplicar

### Para pensar

- ¿Qué número quieres multiplicar?
- ¿Cuántas veces tienes que repetir la operación?
- ¿Qué valores va tomando el multiplicador?
- ¿Cómo puedes construir cada línea del resultado?

### Pistas

- Necesitarás una variable para el número.
- Necesitarás un bucle.
- El bucle deberá recorrer desde 1 hasta 10.
- Dentro del bucle calcularás la multiplicación.
- Tendrás que mostrar cada operación en una línea.

## Ejercicio 4: Comprobar par o impar

### Para pensar

- ¿Qué número tienes que comprobar?
- ¿Qué operación te permite saber si un número se divide exactamente  
  entre 2?
- ¿Qué dos resultados posibles hay?

### Pistas

- Necesitarás una variable para el número.
- El operador `%` devuelve el resto de una división.
- Si el resto de dividir entre 2 es 0, el número es par.
- Si no, el número es impar.
- Tendrás que mostrar el mensaje correspondiente.

## Ejercicio 5: Calcular IVA

### Para pensar

- ¿Qué dato es el precio base?
- ¿Qué porcentaje de IVA hay que aplicar?
- ¿Cómo se calcula el importe del IVA?
- ¿Cómo se obtiene el precio final?

### Pistas

- Necesitarás una variable para el precio.
- Necesitarás una variable para el porcentaje de IVA.
- El IVA se calcula multiplicando el precio por el porcentaje  
  y dividiendo entre 100.
- El precio final es el precio más el IVA.
- Tendrás que mostrar tanto el IVA como el precio final.

## Ejercicio 6: Comparar dos números

### Para pensar

- ¿Qué dos números tienes que comparar?
- ¿Cuántas posibilidades hay?
- ¿Qué estructura te permite decidir cuál es el mayor?
- ¿Qué mensaje debe mostrarse?

### Pistas

- Necesitarás dos variables, una para cada número.
- Necesitarás comparar los dos valores.
- Puedes usar `if`, `else if` y `else`.
- Tendrás que mostrar cuál es el mayor o si son iguales.
