Ejercicios medios

Practica arrays, acumuladores, matrices, bucles y funciones.

Consejo: Si pulsas un botón y no aparece ningún resultado, abre la consola del navegador con F12. Allí podrás ver si hay algún error de sintaxis, en qué archivo está y en qué línea.

Ejercicio 1: Contar aprobados y suspensos

Dado el array de notas [4, 7, 5, 3, 9, 6], cuenta cuántas son aprobados y cuántas suspensos. Se aprueba con una nota mayor o igual que 5.

Resultado esperado: Aprobados: 4 — Suspensos: 2

Ejercicio 2: Encontrar el mayor

Dado el array [-8, -3, -12, -1, -6], encuentra el mayor número sin usar Math.max() ni ordenar el array.

Resultado esperado: El mayor es -1

Ejercicio 3: Calcular la media

Dado el array de notas [6, 8, 4, 10], calcula la media usando un bucle.

Resultado esperado: La media es 7

Ejercicio 4: Sumar una matriz

Dada la matriz [[2, 4, 6], [1, 3, 5]], calcula la suma de todos sus elementos usando bucles anidados.

Resultado esperado: La suma total es 21

Ejercicio 5: Reparto con resto

Hay 23 jamones para repartir entre 10 empleados. Calcula cuántos recibe cada uno y cuántos sobran.

Resultado esperado: Cada empleado recibe 2 — Sobran 3

Ejercicio 6: Función de precio final

Crea una función llamada precioFinal que reciba un precio y un porcentaje de descuento opcional con valor por defecto del 10 %. Debe devolver el precio final.

Muestra el resultado de precioFinal(100) y precioFinal(80, 25).

Resultado esperado: Precio final 1: 90 € — Precio final 2: 60 €
