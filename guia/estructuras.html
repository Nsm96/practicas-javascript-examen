Guía de estructuras JavaScript

Ejemplos clicables de las estructuras principales.

Variables

Usa const cuando el valor no cambia y let cuando sí puede cambiar.

if / else if / else

Permite elegir entre varias posibilidades.

Operador ternario

Es una forma corta de escribir un if/else.

Bucle for

Repite un bloque de código un número determinado de veces.

Función normal

Agrupa código reutilizable y puede devolver un resultado.

Función flecha

Es otra forma de escribir funciones.

Callback

Una callback es una función que se pasa a otra función.

Arrays

Un array guarda una lista de valores.

Objetos

Un objeto guarda datos relacionados mediante propiedades.

filter

Crea un array nuevo con los elementos que cumplen una condición.

map

Crea un array nuevo transformando cada elemento.

find

Devuelve el primer elemento que cumple una condición.

reduce

Acumula un resultado a partir de los elementos de un array.

Spread

Permite expandir los valores de un array dentro de otro.

DOM básico

Permite seleccionar elementos del HTML y modificar su contenido.
